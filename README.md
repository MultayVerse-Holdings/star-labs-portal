# Star Labs Client Portal

Client-facing workspace for Star Labs projects, Adzilla direct-mail campaigns, files, billing, and account management.

## MVP

- Client dashboard
- Projects workspace
- Adzilla campaign status and inventory
- Artwork/proof workflow UI
- Files area
- Billing area
- Account settings

Designed to ultimately live at `https://hellostarlabs.com/client` while remaining a separate application codebase.
